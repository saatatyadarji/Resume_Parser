# Resume_Parser
🧠 Resume Parser using NLP & Python

This project is a Resume Parser that automatically extracts key information from resumes using Natural Language Processing (NLP) techniques in Python. It can identify and extract:

📧 Email IDs

📞 Phone Numbers

🔗 Links / URLs

🧑‍💼 Names

💼 Skills

💻 Projects

⏱ Experience

The project uses NLTK, Regular Expressions, and Text Preprocessing to clean and analyze text efficiently. It’s designed to make resume screening faster and more consistent — a useful tool for HR, recruiters, or data-driven hiring applications.

🔍 Key Features

Extracts structured data from plain or PDF text resumes

Detects popular technical skills (Python, Java, ML, SQL, Power BI, etc.)

Identifies links, emails, and contact numbers accurately

Can be easily extended to parse multiple resumes at once

🧩 Tech Stack

Python 3

NLTK (Natural Language Toolkit)

re (Regular Expressions)

pdfplumber (optional, for reading PDF resumes)

🚀 Future Improvements

Add machine learning to classify resume sections dynamically

Support for multiple resume formats (PDF, DOCX, TXT)

Web app interface using Streamlit or Flask
